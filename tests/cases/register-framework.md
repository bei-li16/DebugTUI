# 寄存器框架延后环境用例

以下 case 初始均为 **SKIPPED / 未执行**。单元及 MI 软件测试不替代宿主终端视觉验收或目标能力验证。记录 DebugTUI／GDB／OpenOCD 路径、版本、SHA-256、工程／目录来源、实际核心／owner、停止上下文和终端种类。硬件读取只使用专用测试固件中已允许的只读对象；本用例不为读取自动使能 FPU、切换模式或修改 MPU／PMU。

软件命令可在仓库根目录执行：`cargo test --locked`、`cargo clippy --locked --all-targets -- -D warnings`、`node scripts/test-functional.cjs --only unit`。Windows 配置本文开发环境的任务内 Cargo／Rustup 路径；不要求替换已安装 release。

| Case | 准备及操作 | 预期结果及证据 |
|---|---|---|
| REG-T01-FRAMEWORK | 用客户目录副本分别加入重复组／寄存器 ID、缺失父组、非法宽度、间接 alias 循环、缺失 reader 参数及 >4 MiB 文件；正常文件放在含中文和空格的目录。仅加载配置，不连接目标 | 非法文件给出具体错误且不回退另一目录；合法文件正确加载并显示来源；保存文件哈希和错误原文 |
| REG-T02-FRAMEWORK | 合法暂停后单次读取 CPSR，展开 N/C/M/IT，按 t 进入字段 Status，逐行或 PageDown 滚动，再 Home／Esc | M=19 时为 AArch32_SVC；IT 按 [26:25]、[15:10] 拼接；父字段不新增 MI/Tcl 读；全部枚举、描述、访问条件、状态原因可访问 |
| REG-T03-FRAMEWORK | 在已验证可读的 64／128 位对象上使用不对称原始高低字，缩至 35×12，查看 Status；若目标无合法 128 位 reader，该步骤如实跳过 | 全部原始位在帮助中可查看；Size／Access 与对象位宽一致；不由目录有定义推断 reader 可用。记录独立固件／后端基线，不以 UI 自身输出作为预期值 |
| REG-T07-FRAMEWORK | 键盘 Right／Enter、鼠标箭头展开 SIMD／Quad，PageDown／滚轮选择；搜索名称及客户中文描述；依次选择 All／Core／SIMD／System；折叠组 | 焦点、选择和滚动正确；分类与描述搜索正确；操作自身只改变偏好；自动读取仅限当前可见且合法条目，折叠组不持续读取扩展项 |
| REG-T05-HIGHLIGHT | 核心 0 的专用固件在两个允许的停止点改变 CPSR.N 或普通测试寄存器；核心 1 使用不同值。切核、换帧、重新连接，再安全读取 | 同一核／会话／帧的前后有效值变化显示琥珀色，未变字段不高亮；首次或跨上下文读取不显示旧变化；不将 peer 值用于当前核比较 |
| REG-T07-PREFERENCES | 更改进制、展开、字段、筛选和格式，保存／重开工程；切到另一核心及另一芯片的同名对象，再返回 | 当前偏好保留；其他核心／芯片／目录不串用；偏好保存不触发目标读取，不修改继承的共享 profile |
| REG-T08-COLUMNS | 分别在 PowerShell、VS Code 终端，以 120×35、80×24、50×12、35×12 查看含中文及长名称的客户目录和 32／64／128 位项目；选择字段访问覆盖；点击值格式菜单 | 宽屏四列对齐，Size／Access 保持可见；窄窗保留名称和值，说明区位宽及访问属性属于选中字段；菜单命中区域位于值列。全值、枚举和原因可通过 t 查看；保存屏幕、终端字体／配色和 MI 请求计数 |

原始目标值必须与固件或已审查的独立后端基线比较。未取得合法权限、实际 reader 或可控停止点的步骤记录原因并保持 SKIPPED，不能记为通过。实际 PowerShell／VS Code 中文、高对比度和鼠标视觉结果另计 REG-208；本轮 Ratatui 测试不勾选该项。
